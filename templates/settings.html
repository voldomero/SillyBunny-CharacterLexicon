Pronoun directive

When a persona or character has two or more pronoun sets, an instruction asks the model to use the same set as the macros. Rotate changes the set between replies. Primary keeps the first set.
Depth and role apply to both pronoun instructions and language preferences. Language preferences have their own switch in each profile. Placeholders: %LIST% = all sets (she/her and they/them). %ACTIVE% = the complete set selected for this reply. {{user}} / {{char}} are resolved normally.
